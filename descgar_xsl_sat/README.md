# Descargador XSLT SAT

Script para descargar archivos XSLT del SAT y todas sus referencias.

## Instalación

```bash
npm install
```

## Uso

```bash
npm start
```

## Características

- Descarga el archivo XSLT principal del SAT
- Extrae y descarga todas las referencias (includes e imports)
- Genera logs detallados en `descarga.log`
- Registra archivos con errores de descarga
- Evita descargas duplicadas
